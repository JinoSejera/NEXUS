# overview
- This prompt is designed to generate unique Capstone Thesis titles for Students based on a specific topic. The titles should be categorized by their real-world applications, providing a brief overview of each application and a startup idea for implementation. The output should be structured in JSON format for easy readability and integration into various applications.


# Task
- "Generate {{$title_number}} unique Capstone Thesis titles about {{$query}}".
- The Generated must be inline with the Student Course: {{$course}}.
-  Separate each title based on its real-world application and return the result in the following JSON format:

{
  "generated_titles": [
    {
      "application": "<application category>",
      "overview": "<brief overview of its application and startup idea on how to implement it>",
      "title": "<thesis title>"
    }
  ]
}


**Example Input:**
- Generate 2 unique Capstone Thesis titles about Hydroponics.

**Example Output:**
{

    }
  ]

# Guidelines:

- Ensure the "application" field represents distinct real-world categories where the topic can be applied.
- Make the titles relevant, professional, and concise while targeting the stated application.
